# WhatsVoiceBubble

تطبيق أندرويد بفقاعة فوق واتساب لتحويل الريكورد إلى نص بدون Share.

## الجديد في الإصدار 1.2.0

- لو وجد آخر ريكورد واتساب محفوظ/متاح على الجهاز، يحوله مباشرة.
- لو لم يجد ريكورد محفوظ، يدخل وضع سماع الريكورد: افتح/شغّل الريكورد في واتساب والتطبيق يسجل صوت الموبايل لمدة 45 ثانية ثم يحوله لنص.
- تم حذف زر "نسخ النص" من نافذة النتيجة.
- تم إضافة خانة Backend URL داخل التطبيق بدل تثبيت الرابط في الكود.
- تم إضافة Backend Python جاهز داخل مجلد `backend`.
- زر فحص التحديث من GitHub ما زال مربوط على `spyzorro/whatsapp`.

## طريقة الاستخدام

1. ثبّت APK.
2. افتح التطبيق.
3. ضع رابط Backend في خانة Backend URL، مثال:

```text
https://your-domain.com/transcribe
```

4. اضغط حفظ رابط Backend.
5. فعّل الظهور فوق التطبيقات.
6. فعّل Accessibility للتطبيق.
7. افتح واتساب.
8. اضغط الفقاعة عند الشات الذي يحتوي على ريكورد.

## مهم جدًا

تطبيق خارجي لا يستطيع تنزيل ريكورد من سيرفرات واتساب مباشرة أو فك تشفير رسائل واتساب. لذلك التطبيق يعمل بطريقتين:

- يقرأ الريكورد إذا أصبح متاحًا كملف على الجهاز.
- أو يسمع الريكورد من صوت الموبايل عندما تشغّله في واتساب.

لو بتستخدم سماعات/هاند فري قد لا يلتقط وضع السماع الصوت جيدًا، لأنه يعتمد على ميكروفون الموبايل.

## GitHub Actions

كل Push على `main` يبني APK كـ Artifact.

لو عملت tag مثل:

```text
v1.2.0
```

هيتم إنشاء Release ورفع APK تلقائيًا.
