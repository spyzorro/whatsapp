# Whats Voice Bubble v1.3.0

نسخة معدلة لحل مشكلة **تم منع التطبيق من الوصول / إعداد محظور**.

## سبب المشكلة

الإصدارات السابقة كانت تطلب Accessibility عشان الفقاعة تظهر تلقائيًا عند فتح واتساب. Android 13/14/15 يمنع أو يحذر من Accessibility للتطبيقات المثبتة كـ APK خارج المتجر، لذلك تم حذف Accessibility من التطبيق بالكامل.

## ما الجديد

- لا يوجد Accessibility Service.
- لا يوجد زر فتح إعدادات Accessibility.
- الفقاعة تعمل بدون الإذن المحظور.
- طرق تحويل متعددة:
  1. البحث في MediaStore Audio عن آخر ريكورد واتساب.
  2. البحث في MediaStore Files عن ملفات OPUS/OGG/M4A.
  3. اختيار فولدر WhatsApp Voice Notes مرة واحدة بصلاحية SAF.
  4. اختيار ملف صوت يدوي للتجربة.
  5. تحويل مباشر من الميكروفون بدون Backend أثناء تشغيل الريكورد.
  6. تسجيل الريكورد أثناء تشغيله ثم إرساله للـ Backend.
- زر التحديث من GitHub ما زال مربوطًا بـ `spyzorro/whatsapp`.

## طريقة الاستخدام

1. ثبّت APK.
2. افتح التطبيق.
3. فعّل الظهور فوق التطبيقات.
4. اضغط تشغيل الفقاعة بدون Accessibility.
5. افتح واتساب واضغط الفقاعة.
6. اختار تحويل ذكي أو اسمع الريكورد بدون سيرفر.

## لتحويل الملفات المحفوظة بدقة عالية

شغل Backend الموجود في فولدر `backend` وضع رابطه في خانة Backend URL.

## للتحديثات

